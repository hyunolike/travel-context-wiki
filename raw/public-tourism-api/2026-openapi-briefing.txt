한국관광공사_국문 관광정보 서비스_GW API 중 detailCommon1 가 contentId 단일건으로만 확인
가능한데, 혹시 list 형태로 호출 할 수 있는 방법은 없나요? 자주 찾는 관광지 목록을 list로 보여주
고자 합니다. 여러건의 contentId의 firstimage 값과 addr, title 값이 필요합니다.

관광지에 대한 url로 검색 가능한 식별코드 같은게 있을까요? 없다면 만들어 주실 수 있을까요?

-> 공사에서는 서비스별로 필요한 오퍼레이션을 만들어 드리지는 않습니다. 주어진 오퍼레이션의
   정보들을 활용 및 조합하셔서 서비스를 제작 하셔야 합니다.



관광공사 api를 하나 이상을 무조건 사용해야 된다고 알고 있습니다. 근데 api에서 데이터를 불러
와서 저희 어플리케이션에 적절한 데이터로 수정해서 db에 저장해 사용해도 조건을 만족하는 것
일까요?

-> 원천 데이터를 수정 하시는 것을 권장 드리지 않습니다.
   만약 필요에 의해서 원천 데이터를 수정 하시면 해당 콘텐츠로 인한 분쟁이 발생시 제공한
   데이터를 변형한 것에 대한 책임은 개발사가 지셔야 함으로 콘텐츠 관리이슈가 발생할 수
   있음으로 신중히 결정 하셔야 합니다.
   또한 사용여부 확인 과정에서 편집된 정보는 확인에 이슈가 발생할 수 있습니다.
