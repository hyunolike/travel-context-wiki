## Observed Project Requirements

- Build an open source AI automation agent project.
- Use Python-centered implementation with FastAPI, LangChain, and LangGraph.
- Treat Obsidian, LLM-Wiki, and Neo4j-based GraphRAG as the knowledge management layer.
- Use Claude Code as a development productivity aid while keeping final evaluation focused on the developer's understanding and technical explanation.
- Use Docker and Hugging Face Spaces as deployment candidates.
- Build a deployable AI demo service and a unified portfolio artifact set.
- Maintain public GitHub contribution artifacts such as issues and pull requests.
- Include planning, evaluation, and deployment artifacts such as PRD, RAGAS evaluation report, and deployed service URL.

## Delivery Phases

1. Environment and data: Python environment, Obsidian knowledge base design, data collection, preprocessing pipeline.
2. RAG and GraphRAG: embeddings, vector retrieval, and Neo4j-backed graph retrieval.
3. Agent development: LangChain and LangGraph multi-step agent design, RAGAS evaluation, improvement loop.
4. Deployment and portfolio: Docker or Hugging Face Spaces deployment, public GitHub repository, PRD, evaluation report, and portfolio-ready documentation.

## Implication For This Wiki

Project documents should be first-class linked artifacts, not loose attachments. Each PRD, evaluation report, deployment URL, GitHub issue, pull request, service package, and knowledge graph export should have a stable artifact record and should be linked back to raw evidence, canonical pages, and service packages.
