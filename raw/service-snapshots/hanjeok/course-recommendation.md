# Scenario: 혼잡 관광지 우회 코스 추천

## 목적

사용자가 방문하려는 관광지가 혼잡할 때, 한적한 대안 관광지와 덜 붐비는 시간대를 조합해 실행 가능한 우회 코스를 제안한다.

## Given

- 사용자는 `경복궁`을 방문 후보로 선택한다.
- 방문 희망 시점은 `2026-08-15 14:00`이다.
- 혼잡도 fixture는 해당 시점의 `경복궁`을 `매우혼잡`으로 분류한다.
- 대안 관광지 fixture에는 도보 또는 짧은 대중교통 이동이 가능한 후보가 포함되어 있다.

## When

- 사용자가 혼잡도 진단을 요청한다.
- 시스템이 연관도, 한적함, 거리 기준으로 대안지를 점수화한다.
- 시스템이 덜 붐비는 시간대 순서로 코스를 재구성한다.

## Then

- 응답은 `경복궁`의 혼잡 상태와 근거 지표를 포함한다.
- 응답은 최소 2개의 대안 관광지를 추천한다.
- 추천 결과는 사용자가 이해할 수 있는 이유를 포함한다.
- 코스는 방문 순서, 예상 혼잡 등급, 공유 가능한 식별자를 포함한다.

## 검증 관점

- 외부 공공 API가 없어도 fixture만으로 같은 결과를 재현할 수 있어야 한다.
- 혼잡 관광지가 아닌 경우에는 무리하게 대안 코스를 강제하지 않는다.
- 추천 점수는 결정적이어야 하며 같은 fixture 입력에서 순서가 바뀌면 안 된다.
